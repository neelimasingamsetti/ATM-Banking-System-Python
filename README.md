## 📌 Features

* 🌐 **Language **: English option .
* 🔐 **PIN Verification**: Validates credentials before menu access.
* 💰 **Balance Inquiry**: Displays live updated account balance.
* 📥 **Deposit System**: Instant balance increment logic.
* 📤 **Withdrawal System**: Real-time checking logic to prevent overdrawing.
